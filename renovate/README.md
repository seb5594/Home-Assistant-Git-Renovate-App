# Renovate

Keeps the dependencies of your GitHub, GitLab, Gitea and Forgejo repositories up to date. Renovate opens a
pull request when something you use has a new version, and this app runs it on your Home Assistant with a
web interface, a schedule and optional webhooks.

**Experimental.** Open the web interface, press **Connect a git server** and start with a preview run.
